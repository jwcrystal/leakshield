# Triage Labels

Map five canonical triage roles to GitHub labels for `jwcrystal/leakshield`.

| Role | Label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified, agent-ready |
| `ready-for-human` | `ready-for-human` | Needs human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use the right-hand label when a skill refers to a role. Change this mapping if the repo's label vocabulary changes.
